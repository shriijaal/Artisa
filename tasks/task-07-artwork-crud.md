# Task 7: Artwork CRUD + Moderation + Originality

**Phase:** Artists (Week 6–7)  
**Depends on:** Task 6  
**Blocks:** Task 8

## Goal

Artists create and manage artworks with moderation workflow and originality declaration.

## Deliverables

- [ ] CRUD `/api/artist/artworks`
- [ ] Artwork lifecycle: `draft` → `pending_review` → `published` → `removed`
- [ ] Originality declaration required on submit
- [ ] Multiple images per artwork; tags; physical stock or digital file upload
- [ ] Admin moderates via Django Admin
- [ ] Public API returns only `published` artworks
- [ ] React: artwork upload/edit form

## Trust features

Verified badge on cards when artist is approved. Originality checkbox on upload form.
